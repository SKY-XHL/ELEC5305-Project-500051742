# Report 1 Audio Samples

This folder contains exactly three five-second ESC-50 recordings selected for Audio Processing Report One.

| Report filename | ESC-50 source filename | Category | Fold | ESC-10 |
|---|---|---|---:|---|
| `rain.wav` | `1-17367-A-10.wav` | rain | 1 | Yes |
| `dog_bark.wav` | `1-30226-A-0.wav` | dog | 1 | Yes |
| `clock_tick.wav` | `1-21934-A-38.wav` | clock_tick | 1 | Yes |

The three files were copied unchanged from the official ESC-50 repository and renamed only to make the MATLAB Live Script easier to read.

They are used as representative examples for time-domain waveform analysis, FFT spectrum analysis, STFT spectrogram analysis, and the STFT window-length comparison.

Do not place the complete ESC-50 dataset in this repository.
